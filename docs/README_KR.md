## 🎯 개요

본 프로젝트는 4×4 입력 행렬과 3×3 필터를 사용하여 2×2 출력을 생성하는 **하드웨어 가속 2D 컨볼루션 엔진**을 FPGA에 구현합니다. 시스템은 서로 다른 데이터플로우 아키텍처를 가진 **세 가지 연산 모드**를 제공합니다:

- **Serial PE 모드**: 최소 하드웨어로 순차 처리 (1개 PE)
- **Systolic Array 3×3 모드**: 조합 체이닝을 통한 수직 누적 (9개 PE) ⭐ **최고 성능**
- **Systolic Array 2×2 모드**: 스큐 입력을 사용한 출력 고정 방식 (4개 PE)

모든 설계는 **진정한 컨볼루션**(180° 필터 회전)을 구현하며, 곱셈-누적 유닛에 **구조적 모델링**(AND 게이트와 전가산기를 사용한 게이트 레벨 설계)을 사용합니다.

## ✨ 주요 특징

### 🔥 고성능
- SA 3×3로 직렬 처리 대비 **2.41배 속도 향상**
- 100 MHz에서 완전한 2×2 컨볼루션에 **32 사이클** 소요 (320 ns)
- 지연 없는 누적을 위한 조합 수직 체이닝

### 🎨 다중 아키텍처
- 교육 및 성능 비교를 위한 **세 가지 독립적인 데이터플로우 패턴**
- 각 아키텍처는 서로 다른 시스톨릭 어레이 설계 원칙을 시연
- 포괄적인 테스트벤치로 완전히 검증됨

### ⚙️ 구조적 설계
- AND 게이트와 전가산기만 사용한 **게이트 레벨 구현**
- 행동 수준 곱셈(`*`) 또는 덧셈(`+`) 연산자 미사용
- 엄격한 구조적 모델링 요구사항 준수

### 🎓 교육적 가치
- 상세한 주석이 포함된 잘 문서화된 코드
- 데이터패스와 제어 로직의 명확한 분리
- 고급 FPGA 설계 개념 시연

## 🔧 모듈 설명

### 1. 처리 요소 (PE) - `pe.v`

PE는 수직 체이닝(SA 3×3)과 출력 고정(SA 2×2) 모드를 모두 지원하는 **이중 누적 경로**를 가진 기본 MAC(Multiply-Accumulate) 유닛입니다.

**주요 특징:**
- **구조적 8×8 곱셈기**: 64개 AND 게이트 + 56개 전가산기
- **이중 누적**:
  - `c_out` (조합): SA 3×3의 수직 체이닝용
  - `acc_out` (레지스터): SA 2×2의 내부 누적용
- **가중치 고정 지원**: 일회성 가중치 로딩을 위한 `load_b` 신호
- **시스톨릭 데이터플로우**: 어레이 연결을 위한 파이프라인 `a_out`, `b_out`

```verilog
// PE 인터페이스
module pe (
    input  wire [7:0] a_in,     // 입력 데이터 (수평 흐름)
    input  wire [7:0] b_in,     // 가중치 데이터 (수직 흐름)
    input  wire [7:0] c_in,     // 누적 입력 (수직)
    input  wire       load_b,   // 가중치 로드 활성화
    input  wire       en,       // PE 활성화
    input  wire       clr_acc,  // 누산기 클리어
    output reg  [7:0] a_out,    // 데이터 출력 (레지스터)
    output reg  [7:0] b_out,    // 가중치 출력 (레지스터)
    output reg  [7:0] acc_out,  // 내부 누산기 (레지스터)
    output wire [7:0] c_out     // 외부 누적 (조합)
);
```

### 2. Serial PE 연산 - `serial_pe_compute.v`

시분할 다중화를 사용하여 단일 PE로 순차 처리합니다.

**아키텍처:**
- **1개 PE**가 모든 36개 MAC 연산을 순차적으로 수행
- 각 출력(C11, C12, C21, C22)을 9+1 사이클에 계산
  - 9 사이클: MAC 연산
  - 1 사이클: 결과 저장 및 누산기 클리어

**성능:** 총 77 사이클 (메모리 오버헤드 포함)

### 3. Systolic Array 3×3 - `sa_3x3.v` ⭐

수직 누적을 사용한 고성능 병렬 아키텍처입니다.

**아키텍처:**
- 3×3 그리드로 배치된 **9개 PE**
- **수직 조합 체이닝**: c_in/c_out 연결 (지연 없음)
- **가중치 사전 로딩**: 연산 전 모든 가중치를 로드하는 3 사이클
- **하단 행 출력**: 행 2(PE6, PE7, PE8)에서만 결과 추출
- **최종 합산**: 2단계 가산기 트리가 3개 열을 결합

**핵심 혁신:** 
- 중간 결과 레지스터 없음 (엄격한 요구사항에 따름)
- 조합 체이닝으로 열당 사이클당 3번의 누적 가능
- 가장 빠른 설계: **32 사이클** (16 로드 + 3 가중치 + 8 연산 + 1 완료 + 오버헤드)

```
PE 레이아웃:                  데이터 흐름:
  PE0  PE1  PE2  (행 0)      A[0..2] → → →
   ↓c   ↓c   ↓c              B[2,1,0]
  PE3  PE4  PE5  (행 1)      A[4..6] → → →
   ↓c   ↓c   ↓c              B[5,4,3]
  PE6  PE7  PE8  (행 2)      A[8..10] → → →
   ↓    ↓    ↓               B[8,7,6]
 출력 합산                   ↓
   C11  C12  (열로부터)      결과
```

### 4. Systolic Array 2×2 - `sa_2x2.v`

스큐 입력 공급을 사용한 출력 고정 아키텍처입니다.

**아키텍처:**
- 2×2 그리드의 **4개 PE**
- **출력 고정**: 각 PE가 하나의 출력 위치 전담
- **스큐 입력**: 적절한 데이터 정렬을 위한 시차 타이밍
- **이중 출력 사용**:
  - `c_out`: 상단 행 결과 포함 (C11, C12)
  - `acc_out`: 자체 누적 결과 (C21, C22)

**성능:** 36 사이클 (18 로드 + 16 연산 + 2 완료)

```
PE 레이아웃:                  출력 매핑:
  PE0 ──► PE1                 PE2.c_out   = C11
   ↓       ↓                  PE2.acc_out = C21
  PE2 ──► PE3                 PE3.c_out   = C12
                              PE3.acc_out = C22
```

### 5. 컨트롤러 FSM - `controller_fsm_fpga.v`

자동 시작 및 모드 시퀀싱을 가진 메인 시스템 컨트롤러입니다.

**상태:**
1. **IDLE**: 리셋 후 초기 상태
2. **AUTO**: 자동 시작 지연 (~10ms, 안정화용)
3. **SERIAL**: Serial PE 모드 실행
4. **SA3X3**: SA 3×3 모드 실행
5. **SA2X2**: SA 2×2 모드 실행
6. **DONE**: 결과 유지, 디스플레이 활성화

**특징:**
- 자동 모드 시퀀싱 (수동 개입 불필요)
- start/done 신호를 사용한 깔끔한 핸드셰이크
- 메모리 주소 라우팅을 위한 모드 멀티플렉싱

### 6. 메모리 저장소 - `memory_storage.v`

입력 행렬과 필터를 위한 테스트 벡터를 포함하는 ROM입니다.

**테스트 데이터:**
```
입력 행렬 A (4×4):            필터 B (3×3):
┌──────────────────┐          ┌─────────────┐
│  3   4   5   6   │          │  1   0   1  │
│  7   8   9  10   │          │  2   3   2  │
│ 11  12  13  14   │          │  1   0   1  │
│ 15  16  17  18   │          └─────────────┘
└──────────────────┘

예상 출력 (2×2, 180° 필터 회전 후):
┌─────────────┐
```

## 🧮 수학적 배경

### 진정한 컨볼루션 (180° 필터 회전)

이 구현은 상관관계(correlation)가 아닌 **진정한 2D 컨볼루션**을 수행합니다.

**표준 컨볼루션 정의:**
```
(A ⊗ B)[i,j] = ΣΣ A[i+m, j+n] × B[-m, -n]
```

**구현 (필터 회전):**
```
원본 필터 B:                 180° 회전:
┌─────────────┐              ┌─────────────┐
│ B0  B1  B2  │              │ B8  B7  B6  │
│ B3  B4  B5  │  ────────►   │ B5  B4  B3  │
│ B6  B7  B8  │              │ B2  B1  B0  │
└─────────────┘              └─────────────┘

메모리 레이아웃: [B0, B1, ..., B8] → 접근: [B8, B7, ..., B0]
```

**출력 계산:**
```
C11 = A0×B8 + A1×B7 + A2×B6 + A4×B5 + A5×B4 + A6×B3 + A8×B2 + A9×B1 + A10×B0
C12 = A1×B8 + A2×B7 + A3×B6 + A5×B5 + A6×B4 + A7×B3 + A9×B2 + A10×B1 + A11×B0
C21 = A4×B8 + A5×B7 + A6×B6 + A8×B5 + A9×B4 + A10×B3 + A12×B2 + A13×B1 + A14×B0
C22 = A5×B8 + A6×B7 + A7×B6 + A9×B5 + A10×B4 + A11×B3 + A13×B2 + A14×B1 + A15×B0
```

## 🎓 설계 원칙

### 1. 구조적 모델링
모든 산술 연산은 게이트 레벨 프리미티브를 사용합니다:
- **곱셈**: 64개 AND 게이트 + 56개 전가산기 (Wallace 트리)
- **덧셈**: 8비트 리플 캐리 가산기 (8개 전가산기)
- **행동 수준 연산자 없음**: 구조적 설계에 대한 엄격한 준수

### 2. 관심사의 분리
- **데이터패스 모듈** (`.v`): 순수 하드웨어 연결
- **컨트롤러 모듈** (`_controller.v`): FSM 및 제어 신호
- 모듈성을 위한 깔끔한 인터페이스 경계

### 3. 시스톨릭 설계 패턴
- **가중치 고정**: 가중치를 한 번 로드하고 재사용
- **출력 고정**: 각 PE가 고정된 출력 위치 소유
- **수직 누적**: 속도를 위한 조합 체이닝

### 4. 중간 결과 없음 (SA 3×3)
- 상단 및 중간 행 `acc_out` 신호는 최종 결과에 **사용되지 않음**
- 하단 행 `c_out` 신호만 출력에 기여
- 엄격한 요구사항 준수: "Intermediate Result 사용 시 감점!"

### 5. 검증 주도 개발
- 각 모듈에 대한 포괄적인 테스트벤치
- 결과 검증을 위한 황금 참조 값
- 성능 메트릭 추적 (사이클 수)
